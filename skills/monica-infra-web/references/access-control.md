# Authentication, authorization, and CORS

Inside the host's `builder.AddMonica(monica => { ... })` callback, `AddAuthentication(options => { ... })` configures JWT bearer validation with `Issuer`, `Audience`, and `Secret`; the option defaults are placeholder values, so supply application-owned settings before accepting tokens. `AddWebApi()` requires this authentication module, but does not configure real application credentials. Its middleware runs after routing. Bearer tokens from query strings are ignored unless `AllowQueryStringAccessTokens(pathPrefixes)` explicitly enables narrowly scoped transport paths, such as a browser WebSocket hub.

When application requests need Monica permission-bit enforcement, register `AddAuthorization<TEnum>(claimTypeDefinition)` separately. It declares the primary permission-bit contract, authorization middleware, and an execution behavior filtered to business operations that require authorization; it also requires authentication, localization, exception mapping, and the execution pipeline. Additional enums use `AddPermissionBit<TEnum>(claimTypeDefinition)`. The primary enum is required for this module's feature contract. `ConfigAsAlwaysAllow()` replaces permission and authorization checks, so reserve it for explicitly trusted hosts. A Web host is required.

`AddCors().ConfigureDefaultPolicy(...)` or `.AllowAll()` sets the origin policy and runs before authentication in Monica's module order. Choose `AllowAll()` only when that origin policy is intentional. If a browser request fails while the same endpoint works server-to-server, inspect the selected CORS policy and middleware composition before changing JWT validation. For endpoint and Swagger visibility, use [api-documentation-and-visibility.md](api-documentation-and-visibility.md); whether a route exists is separate from whether a caller may access it.

Verify current APIs and order in `Monica.Authority/Modules/ModuleAuthentication.cs`, `Monica.Authority/Modules/ModuleAuthorization.cs`, and `Monica.Authority/Modules/ModuleCors.cs`. `Monica.WebApi/Modules/ModuleWebApi.cs` shows that bundle membership includes authentication but not permission-bit authorization or CORS.

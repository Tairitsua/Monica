# Monica Grove Theme Design Language

Grove is an optional theme identified by `MonicaThemeKind.Grove` and the `grove` CSS token. It provides warm stone surfaces, forest accents, and editorial identity without changing the preserved `MonicaThemeKind.Default` palette. Select Grove in Appearance or configure it as a host's first-visit theme explicitly.

Use the shared [working-interface language](monica-workbench-design-language.md) for page composition, readable evidence, responsive containment, and acceptance, and [Precision's theme and shell contract](monica-precision-design-language.md) for shared navigation, interaction, local assets, and card hooks. Sidebar and Topbar placement are independent of theme selection; both must remain usable under Default, Grove, and every other selectable theme.

## Surface and color roles

- Use a warm stone canvas, a light ordinary surface, a distinct contextual navigation surface, and forest primary/focus accents. Keep the inverse forest identity surface distinct from ordinary working panels.
- Dark mode uses distinguishable green-black canvas and structural surfaces with a softer light primary accent. Retain separate information, success, warning, and error roles and reinforce their meaning with labels or icons.
- Source all component paint from MudBlazor palettes or approved semantic tokens. Grove-specific colors belong in its C# palette and theme-owned CSS.
- Grove paints the shared [visual language](monica-visual-language.md) with forest Primary, its info and secondary roles, and warm stone surfaces. It may add inverse forest identity surfaces, an editorial display face for page titles, and botanical or vector detail. The signature region, role map, and scale tiers stay the same as in every other theme.

## Typography and identity

- Serve IBM Plex Sans locally for interface and dense data text, Playfair Display for major editorial headings, Noto Serif SC for CJK display coverage, and Geist Mono for diagnostic/code evidence. Preserve the declared fallback stacks and local WOFF2 delivery.
- Keep navigation labels, controls, table headers, and supporting titles in the interface family. Serif display text establishes page identity rather than slowing repeated operational scanning.
- Preserve Sidebar typography: contextual identity uses 22px at weight 550 with separate 11px metadata lines and a divider; category headings use 17px at weight 500; destination labels use 13px at weight 400, or 500 when active. Use 42px rows with 4–6px gaps and 4px dots rather than prominent leaf icons. These accepted component-owned metrics do not prescribe the visual prominence of page content or replace Default's global typography.
- Built-in category controls use local SVG outlines at 20px with 1.5px strokes. Keep registered custom icons usable and retain accessible labels on icon-only controls.
- Use the shell's shared `MoNavigationGroup` disclosure for nested capability groups and mobile root areas. Keep capability headings restrained, the actual authorized destination count small, and chevrons at 14px. Mobile root icons remain 20px inside a touch target of at least 44px; enlarging the touch target must not enlarge its icon. Align the brand separator and navigation inset deliberately, and place a thin vertical rule outside the nested destination rows. Selected destinations use a soft Primary tonal surface, a leading quiet dot, and a small trailing indicator rather than a heavy icon or edge strip. Preserve this vocabulary in expanded Sidebar, temporary context, Topbar overflow, and mobile navigation.
- Check supporting navigation text against the actual contextual surface, not just the ordinary Surface palette. The shell mixes TextSecondary with 15% TextPrimary for metadata, counts, and inactive destination text so the light Grove context retains readable small text; keep these roles theme-derived in every mode.
- Collapsed desktop navigation opens a full-height 226px temporary context beside the 64px rail, without changing persisted collapse or reserving expanded page width. Keep the rail available for category switching; support native keyboard disclosure and links, Escape, and outside dismissal. Restore category-trigger focus on dismissal while allowing a changed route to focus its destination. Verify rail scrolling in short viewports.
- Use the shared Monica vector component with Grove's leaf accent, palette, and frame treatment. A preview uses its scoped theme parameters and token roles; it must not acquire global application wrapper styles.
- Verify the theme in both color modes and both desktop navigation layouts, including collapsed navigation, nested popups, Appearance previews, and the temporary mobile drawer. Compare type metrics, content density, and surface separation as well as color.
